# Gwangju Startup Investment AI Analyst

광주 상가정보 공공데이터를 활용한 소상공인 창업 투자 분석 Streamlit 앱입니다.

## 주요 기능
- 광주광역시 상가정보 공공데이터 분석
- 관심 업종별 행정동 분포
- 업종별 경쟁강도 분석
- 행정동별 창업 투자 점수 산출
- 정책화폐 적합도와 문화관광 연계성 반영
- AI 창업 투자 리포트 자동 생성
- Before vs After 및 수업 연계 설명 탭 제공

## 창업 투자 점수 산식
시장수요 35% + 경쟁완화 25% + 상권다양성 15% + 정책화폐 적합도 15% + 문화관광 연계성 10%

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
