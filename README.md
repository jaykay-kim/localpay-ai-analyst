# LocalPay AI Analyst - Service Final

수원시 지역화폐 결제데이터 기반 창업 업종·입지 분석 서비스입니다.

## 서비스 목적

수원시에서 창업을 검토하는 예비창업자가 지역과 업종을 선택하면, 실제 지역화폐 결제데이터와 상가정보를 바탕으로 다음 질문에 답하도록 돕습니다.

- 어떤 업종이 지역화폐 기준으로 결제수요가 높은가?
- 어떤 업종이 경쟁이 강한 레드오션인가?
- 관심 업종은 어느 행정동에서 입지가 좋은가?
- 주요 소비 연령대와 성별은 누구인가?
- 창업 전 추가로 확인해야 할 리스크는 무엇인가?

## 포함 데이터

- `data/suwon_localpay_payments.csv`
  - 수원시 지역화폐 결제정보
  - 기준년월: 2025년 11월
  - 정상 결제 데이터: 5,036행
  - 포함 정보: 읍면동, 업종, 성별, 연령대, 결제건수, 결제금액

- `data/suwon_stores.csv`
  - 경기도 상가정보에서 수원시 관련 행만 추출한 경량 파일
  - 행 수: 56,003행

- 경기지역화폐 가맹점 현황 OpenAPI 조회 결과
  - SIGUN_NM=수원시
  - list_total_count=37,369

## 화면 구성

1. 수원시 전체 현황 대시보드
2. 창업 조건 선택
3. 추천 요약
4. 업종 유망도
5. 지역·입지 분석
6. 관심 업종 상세
7. 고객층 분석
8. AI 창업 리포트
