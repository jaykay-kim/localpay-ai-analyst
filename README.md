# LocalPay AI Analyst - Final

수원시 지역화폐 결제데이터 기반 예비창업자용 창업 투자 의사결정 지원 플랫폼입니다.

## 최종 포지셔닝

이 프로젝트는 지역화폐 결제 데이터를 하나의 상권 투자 데이터로 해석합니다.  
예비창업자는 특정 지역과 업종에 자본을 투입하기 전, 실제 지역화폐 결제금액·결제건수·연령대별 소비패턴을 확인할 수 있습니다.  
즉, AI Analyst가 주식·코인 데이터를 분석하듯이 지역 상권의 소비 데이터를 분석해 창업 투자 의사결정을 보조하는 사례입니다.

## 서비스 이용자

- 1차 이용자: 수원시에서 창업을 검토하는 예비창업자
- 2차 이용자: 소상공인 컨설턴트, 지자체 상권지원 담당자

## 포함 데이터

- `data/suwon_localpay_payments.csv`
  - 공공데이터포털 경기도 수원시_지역화폐 결제 정보
  - 기준년월: 2025년 11월
  - 행 수: 5,037행
  - 포함 정보: 읍면동, 업종, 성별, 연령대, 결제건수, 결제금액

- `data/suwon_stores.csv`
  - 경기도 전체 상가정보에서 수원시 관련 행만 추출한 경량 파일
  - 행 수: 56,003행

- 경기지역화폐 가맹점 현황 OpenAPI 조회 결과
  - SIGUN_NM=수원시
  - list_total_count=37,369

## 주요 기능

- 사용자 결론 카드: 추천 업종 TOP3, 추천 행정동 TOP3, 수요-경쟁 관점 우선 검토 업종
- Before vs After
- 읍면동별 결제금액
- 업종별 결제금액
- 연령대·성별 소비패턴
- 수원시 상가정보 기반 경쟁밀도 보완
- 업종별 창업 투자 점수
- 행정동별 상권 투자 점수
- 수요-경쟁 매트릭스
- 설명적 회귀분석
- AI Analyst Report 자동 생성

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 발표 핵심 문장

최종 시연은 공공데이터포털의 2025년 11월 수원시 지역화폐 결제정보를 사용합니다. 이 데이터에는 읍면동, 업종, 성별, 연령대, 결제건수, 결제금액이 포함되어 있어 실제 지역화폐 소비 데이터를 기반으로 예비창업자의 업종·입지 선택을 지원할 수 있습니다. 여기에 수원시 상가정보와 수원시 지역화폐 가맹점 수 37,369개를 결합해 향후 경쟁강도와 점포당 소비 잠재력 분석으로 확장할 수 있습니다. 분석 구조는 광주상생카드나 온누리상품권 데이터가 확보되면 광주에도 동일하게 적용 가능합니다.
