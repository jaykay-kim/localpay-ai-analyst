# 💳 LocalPay AI Financial Analyst

**수원시 지역화폐 결제데이터 기반 소상공인 창업 투자 상권분석 플랫폼**

> AI Financial Analyst 수업 기말 발표 프로젝트

## 핵심 요약 (두괄식)

예비창업자가 감이 아닌 **실제 지역화폐 결제 데이터**로 창업 업종과 입지를 선택할 수 있도록 돕는 AI Analyst 플랫폼입니다.

## Before vs After

| 구분 | Before | After |
|------|--------|-------|
| 의사결정 근거 | 네이버 지도, 지인 추천, 체감 | **실제 결제금액·건수 데이터** |
| 분석 방법 | 없음 | OLS 회귀분석 + 투자점수 산출 |
| 결과물 | 주관적 판단 | 리스크-수익 매트릭스 + 투자 제안 |

## 데이터 출처

| 데이터 | 제공기관 | 기준일 |
|--------|---------|--------|
| 수원시 지역화폐 결제정보 | 공공데이터포털 | 2025.11 |
| 상가(상권)정보 | 소상공인시장진흥공단 | 2026.03 |
| 지역화폐 가맹점 현황 | 경기지역화폐 OpenAPI | 실시간 |

## 분석 방법론

- **기초통계량**: 평균/중위수/왜도/첨도/분포 분석
- **OLS 회귀분석**: ln(결제금액) ~ 업종+연령대+성별+지역 더미변수 (R² 포함)
- **투자점수**: 수요규모 35% + 거래빈도 20% + 객단가 15% + 확장성 20% + 경쟁완화 10%
- **리스크-수익 매트릭스**: 업종별 기대수익 vs 경쟁리스크 시각화
