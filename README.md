# LocalPay AI Analyst - Suwon Final

광주 앱의 구조를 유지하면서, 최종 시연 데이터는 실제 수원시 지역화폐 결제정보와 경기도 상가정보를 결합한 버전입니다.

## 포함 데이터
- `data/suwon_localpay_payments.csv`
  - 공공데이터포털 경기도 수원시_지역화폐 결제 정보
  - 기준년월: 2025년 11월
  - 포함 정보: 읍면동, 업종, 성별, 연령대, 결제건수, 결제금액
- `data/suwon_stores.csv`
  - 업로드된 경기도 상가정보 중 수원시 필터
- 수원시 전체 지역화폐 가맹점 수
  - 경기지역화폐 가맹점 현황 OpenAPI
  - SIGUN_NM=수원시
  - list_total_count=37,369

## 주요 기능
- Before vs After
- 읍면동별 결제금액
- 업종별 결제금액
- 연령대·성별 소비패턴
- 경기도 상가정보 기반 상가 밀도 확인
- 업종별 창업 투자 점수
- 행정동별 상권 투자 점수
- 관심 업종 입지 검토 점수
- AI Analyst Report 자동 생성

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 발표 포지셔닝
처음에는 광주 지역을 대상으로 지역화폐·온누리상품권 기반 상권분석을 구상했지만, 실제 광주 지역화폐 결제 원천데이터 확보가 어렵다는 한계가 있었습니다. 그래서 최종 시연에서는 실제 결제금액과 결제건수가 공개되어 있는 수원시 지역화폐 결제정보를 활용했습니다. 분석 구조는 광주상생카드나 온누리상품권 데이터가 확보될 경우 광주에도 동일하게 적용 가능합니다.
