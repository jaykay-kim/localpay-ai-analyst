# LocalPay AI Analyst - Service Final v2

수원시 지역화폐 결제데이터 기반 창업 업종·입지 분석 서비스입니다.

## 반영된 최종 수정사항

1. 지역·입지 분석 개선
   - 특정 동 하나를 선택해도 해당 구 또는 수원시 전체 주요 행정동과 함께 비교되도록 개선했습니다.
   - 단일 막대만 보이는 문제를 해결하고, 상권투자점수 비교 + 상가점포수/결제금액 산점도를 함께 제공합니다.

2. 관심 업종 상세분석 개선
   - 추천 입지를 TOP 3 카드로 제공합니다.
   - 각 추천 입지별 입지검토점수, 결제금액, 결제건수, 평균 객단가, 관심업종 점포 수를 보여줍니다.

3. AI 창업/투자 리포트 강화
   - 탭 명칭을 AI 창업/투자 리포트로 변경했습니다.
   - Scoring Model, Demand-Competition Matrix, Explanatory Regression 등 분석기법 설명을 반영했습니다.
