# 발표 설명 문구

## 앱과 발표자료의 역할 분리
앱 화면에서는 실제 이용자가 창업 조건을 선택하고 결과를 확인하는 서비스 흐름만 보여줍니다. 교수님 피드백 반영, 광주에서 수원으로 전환한 이유, 수업과의 연결성은 발표자료에서 별도로 설명합니다.

## 한 줄 주제
LocalPay AI Analyst: 수원시 지역화폐 결제데이터 기반 창업 업종·입지 분석 서비스

## 서비스 이용자
1차 이용자는 수원시에서 창업을 검토하는 예비창업자입니다. 2차 이용자는 소상공인 컨설턴트와 지자체 상권지원 담당자입니다.

## 앱 시연 순서
1. 수원시 전체 현황 대시보드 확인
2. 왼쪽에서 창업 희망 구/동, 관심 업종, 분석 목적 선택
3. 분석하기 클릭
4. 추천 요약에서 추천 업종, 추천 행정동, 우선 검토 업종 확인
5. 업종 유망도에서 레드오션/우선검토 업종 확인
6. 지역·입지 분석에서 소비력이 높은 행정동 확인
7. 관심 업종 상세분석에서 선택 업종의 추천 입지 확인
8. 고객층 분석에서 연령대·성별 소비패턴 확인
9. AI 창업 리포트에서 최종 요약 확인

## 발표에서 설명할 포인트
처음에는 광주 지역을 대상으로 지역화폐·온누리상품권 기반 상권분석을 구상했지만, 실제 광주 지역화폐 결제 원천데이터 확보가 어려웠습니다. 그래서 최종 시연은 실제 결제금액과 결제건수가 공개된 수원시 지역화폐 결제정보를 활용했습니다. 분석 구조는 광주상생카드나 온누리상품권 데이터가 확보될 경우 광주에도 동일하게 적용 가능합니다.
